# CSA09 Java Assignment 1 – Campus Smart-Parking System

This repository is organized into one folder per original assignment task (Task01–Task12). Each folder contains the task-specific source/evidence appropriate to that task. Analytical tasks (1 and 2) contain design write-ups and sample data because the assignment does not prescribe standalone Java programs for them.

## Requirements and execution
- Java: JDK 17 or later (the source uses modern Java syntax).
- Each executable task includes `output.txt`, `output.png`, and `execution.txt` generated by compiling and running the Java source in this package.
- `input.txt` or `test-cases.txt` records the sample scenario where applicable. Some supplied demonstration programs use fixed sample values in `main()` rather than interactive Scanner input.

## Compile and run
For a single-file task, open its folder in VS Code and run the `.java` file, or use:

```powershell
javac -d out *.java
java -cp out MainClassName
```

For Tasks 10–12, from the task folder run:

```powershell
javac -d out src/parking/model/*.java src/parking/service/*.java src/parking/app/*.java
java -cp out parking.app.Main
```

## Git workflow
Commit progressively, with at least one meaningful commit for each task. Do not make one final bulk commit.

The `.png` files are generated terminal-style captures of the actual program output, not photographs of the user's VS Code window. For a faculty requirement that specifically asks for IDE screenshots, run each program on your computer and capture your own VS Code terminal.
